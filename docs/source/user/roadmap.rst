Quick Start
===========

New to Varm? Start here for a fast introduction to the core concepts and get
your first program running in minutes.

→ :doc:`Go to Quick Start <quickstart>`

Tutorial Sequence
=================

Progress through the tutorials in order to build a comprehensive understanding
of Varm. Each tutorial builds on concepts from the previous one.

1. **Introduction** — Core concepts and philosophy
2. **Instruction Set** — Understanding Varm's instruction architecture
3. **Memory Model** — How memory is organized and accessed
4. **System Calls** — Interacting with the operating system
5. **Examples** — Practical examples combining all concepts
